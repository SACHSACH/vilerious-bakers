# Vilerious Bakers

A responsive static website for Vilerious Bakers in Machakos, Kenya.

## Hosting

GitHub Pages serves this static site from the root of the `main` branch.

Once the first deployment completes, the public site is available at:

<https://sachsach.github.io/vilerious-bakers/>

## Cake gallery

The gallery uses Supabase for public media and authenticated management. Follow [GALLERY_SETUP.md](./GALLERY_SETUP.md) and run the SQL in [`supabase/setup.sql`](./supabase/setup.sql) before using the private gallery manager at `/admin.html`.
